# E-Commerce Customer Journey and Sales Analytics

## Project Overview

This project analyzes customer interactions on an e-commerce platform to understand customer behavior, sales performance, marketing effectiveness, and conversion funnel performance. The objective is to uncover actionable insights that can help businesses optimize their marketing strategies, improve customer conversion rates, and maximize revenue.

This project was developed as part of my data analytics portfolio to demonstrate proficiency in data analysis, visualization, and storytelling using Python.

## Business Problem

E-commerce businesses generate large volumes of customer interaction data, but often struggle to answer critical business questions such as:

* How much revenue was generated?
* Which products generate the highest sales?
* Which marketing channels are most effective?
* Where do customers abandon the purchasing process?
* What factors influence customer conversion?

This project seeks to answer these questions through exploratory data analysis and interactive visualizations.
